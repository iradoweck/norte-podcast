# Security Policy — Norte Podcast & BLN

## Supported Versions

We actively maintain and provide security updates for the following versions of the project:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

We take the security of our platform, viewers, and partners seriously. If you discover a security vulnerability within this repository or associated assets, please follow these steps:

1. **Do NOT report vulnerabilities through public GitHub issues.**
2. Please send an email directly to security / engineering support:
   - **Email:** `security@zedecks.com`
   - **Organization:** XBetter Moçambique, SU, Lda. / ZedeckLab
3. Please include:
   - Type of issue (e.g., XSS, CSRF, sensitive data exposure, API key leak).
   - Step-by-step instructions or Proof of Concept (PoC) to reproduce the issue.
   - Potential impact of the vulnerability.

---

## Response Times & Handling

- **Acknowledgment:** Within 24 hours of receiving the report.
- **Assessment & Triage:** Within 48–72 hours.
- **Remediation & Patch Release:** Priority fixes deployed immediately according to severity level.

We appreciate the responsible disclosure of any security matters.
